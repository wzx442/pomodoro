# 番茄钟 · 专注计时与复盘

一个**零依赖、纯本地**的番茄钟。多任务计时、倒计时 / 正向计时、番茄循环、记录汇总与可视化分析，全部在一个网页里完成。

![计时界面](preview/timer-dark.png)

## 打开方式

- **推荐**：双击根目录的 `番茄钟.html`（单文件，离线可用，可直接发给别人）。
- 源码版：用浏览器打开 `pomodoro/index.html`，功能与单文件版完全一致。

数据保存在浏览器的 `localStorage`（键名 `tomato.v1`），**不会上传到任何服务器**。清理浏览器数据或换浏览器前，请先在「设置 → 数据」里导出 JSON 备份。

## 功能

**计时**
- 倒计时：15 / 25 / 45 / 60 分钟预设，或「自定义」任意时长。
- 正向计时：不限时长，随时结束，按实际时长入账。
- 番茄循环：专注 → 短休息 → 长休息（默认每 4 轮长休），显示轮次圆点。
- 可选自动开始下一段（专注后自动休息、休息后自动专注）。
- 计时基于真实时间戳，切后台、锁屏、刷新页面都不会走偏；刷新后能恢复正在进行的计时。

**任务**
- 任意新建 / 改名 / 换色 / 删除任务，侧栏显示每个任务今天的投入。
- 已删除任务的历史记录会保留当时的名称和颜色。

**统计（今日 / 本周 / 本月 / 全部）**
- 四个关键指标：专注时长（含环比）、完成番茄、完成率、日均专注与达标天数。
- 近 14 天柱状图：每日专注分钟数，带目标线。
- 任务分布环图：各任务时间占比。
- 高效时段热力图：近 4 周「星期 × 小时」的平均专注强度。
- 自动生成的洞察：环比变化、黄金时段、效率最高的一天、投入最多的任务、连续天数。
- 记录明细：可筛选、删除，支持导出 CSV。

![统计界面](preview/stats-light.png)

**其他**
- 深色 / 浅色主题（默认跟随系统）。
- 桌面与手机自适应，手机端侧栏为抽屉。
- 结束提示音、系统通知（需授权）。
- JSON 导入 / 导出、CSV 导出、清空数据、示例数据。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 开始 / 暂停 |
| `R` | 重置当前计时 |
| `S` | 跳过 / 结束当前阶段 |
| `1` | 切换到倒计时 |
| `2` | 切换到正向计时 |

在输入框内或弹窗打开时，快捷键自动失效。

## 统计口径

| 指标 | 口径 |
| --- | --- |
| 专注时长 | 专注记录的实际时长之和（休息不计入） |
| 完成番茄 | 倒计时自然走完的专注次数 |
| 完成率 | 完成番茄 ÷ 倒计时专注次数 |
| 日均专注 | 专注时长 ÷ 时间范围内已过天数 |
| 达标天数 | 当天专注分钟 ≥ 每日目标 的天数 |
| 较上期 | 与上一周期「相同已过时长」比较，避免拿半天比整天 |
| 黄金时段 | 近 4 周累计专注最多的小时 |
| 热力图 | 近 4 周内，该「星期 + 小时」的平均专注分钟 |
| 连续天数 | 截止今天的连续有记录天数（今天还没记录则从昨天开始算） |

短于 30 秒的计时不会生成记录，避免误触产生噪声。

## 设置

- 专注 / 短休 / 长休时长、每几轮长休、每日目标。
- 提示音、系统通知、自动衔接。
- 数据导入导出与清空。

## 文件结构

```
番茄钟.html              单文件应用（由下面的源码构建）
pomodoro/
  index.html             页面结构
  styles.css             样式（含深/浅主题）
  app.js                 计时、任务、统计、导入导出
  build.mjs              构建单文件版本
  preview/               截图
  README.md
```

修改源码后重新生成单文件：

```bash
node pomodoro/build.mjs
```

## 自定义

- 主题色：改 `styles.css` 里的 `--accent` / `--accent-2`（默认番茄红 `#ff6b5e`）。
- 任务配色：改 `app.js` 顶部的 `COLORS` 数组。
- 默认任务与参数：改 `defaultState()` / `defaultSettings()`。

## 说明

- 提示音使用 Web Audio 合成，不需要音频文件；浏览器要求先有用户点击才能出声，正常点击「开始」后即可。
- 系统通知需要 HTTPS 或 localhost 环境；直接双击本地文件时，部分浏览器会禁用通知，但计时与统计不受影响。
- 若浏览器禁用了本地存储，应用仍可使用，但刷新后数据不会保留。
